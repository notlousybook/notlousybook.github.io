## Priority Issues

### [P2] `?` key shortcut is invisible to most users
- What: Pressing `?` logs help text to console. No visual feedback.
- Fix: Show a brief toast notification or add "Press ? for help" hint.

### [P2] Page transition fallback flash
- What: When View Transitions API is unavailable, display: none/block toggling creates a brief flash.
- Fix: Use opacity and visibility instead of display toggle.

### [P3] Stat counter initial flash
- What: Counter starts at "0" before animating up on scroll.
- Fix: Pre-set to a reasonable minimum or start from 1.
