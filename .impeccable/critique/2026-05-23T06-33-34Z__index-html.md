## Anti-Patterns Verdict

Does NOT look fully AI-generated — OKLCH palette, double-bezel cards, and authentic voice save it. But brushes close: "builds things / breaks things" hero line is a template-grade SaaS cliché. Gradient text on hero accent is the absolute-ban. Repeated section-eyebrow pattern is the brand ban. Outfit is a reflex-reject font.

## Overall Impression

A portfolio with genuine personality and solid craft (OKLCH colors, double-bezel cards, scroll reveals, easter eggs) held back by 2-3 template reflexes. The biggest opportunity: replace gradient text and generic hero line with something that matches the confident, playful voice everywhere else.

## What's Working

1. **Color system**: Teal-tinted OKLCH dark palette is tasteful. Proper chroma control.
2. **Double-bezel card**: card-shell/card-core nesting with 1.5px inner border is creative. Best component.
3. **Voice authenticity**: "dumb ahh dev from pluto", Konami code, 5-click logo egg — real personality.

## Priority Issues

- **[P1] Gradient text (absolute ban)**: Hero title accent uses background-clip: text gradient. Fix: use solid var(--accent).
- **[P1] Cringe hero line**: "builds things / breaks things" is a SaaS cliché. Fix: replace with specific work.
- **[P2] Reflex-reject font**: Outfit is a training-data default.
- **[P2] Repeated eyebrow pattern**: Same tiny pill above every heading. First one works; repeating is AI scaffolding.
- **[P2] Em dashes**: Scattered in about text, footer, console.log.
- **[P3] Project detail SPA lacks history**: No pushState, no back button support.
- **[P3] "discordd" typo**: Config and console.log.
