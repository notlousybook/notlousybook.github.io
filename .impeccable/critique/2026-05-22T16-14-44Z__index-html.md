## Anti-Patterns Verdict

**LLM assessment**: This largely avoids the "AI made this" look. The authentic voice, deliberate OKLCH teal palette, and custom Three.js particles feel handmade. However, the stat-row template (big numbers + small labels) flirts with the hero-metric ban, and the identical card grids in projects/collab/stats sections create repetition that reads as templated.

**Deterministic scan**: Unavailable (bundled detector not loaded).

### Issues Found by Manual Code Analysis
1. Undefined CSS variables (`--accent-cyan`, `--accent-violet` used in config.js but never defined in style.css) -> marquee dots render invisible.
2. Dead footer links: Privacy and Terms point to `#`.
3. Marquee animates on infinite loop with no pause control.

## Overall Impression
Genuinely charming portfolio with strong personality. Teal palette, particles, and casual copy all work together. Tightening execution on CSS variables and dead links is the main opportunity.

## What's Working
1. Voice and personality in the copy is the site's strongest asset.
2. OKLCH color system creates a warm dark theme.
3. Three.js particles with mouse interaction signal craft without distracting.

## Priority Issues

### [P1] Undefined CSS variables break marquee and collab icons
- What: `--accent-cyan` and `--accent-violet` referenced 8 times in config.js but never declared in style.css.
- Fix: Add missing CSS variables to `:root` in style.css.

### [P1] Continuous marquee animation risks motion sickness
- What: `.marquee-strip` animates on infinite loop with no pause mechanism.
- Fix: Add pause-on-hover, prefers-reduced-motion static fallback, or aria-hidden.

### [P2] Dead footer links
- What: Privacy and Terms links at index.html:309-310 have href="#".
- Fix: Link to real pages or remove them.

### [P2] Identical card grids across 3 sections
- What: Projects, collab, stats all use same card pattern with hover lift.
- Fix: Vary visual treatment per section.

### [P3] No scroll position preservation on project detail back-nav
- What: hideProjectDetail resets scroll to 0 instead of previous position.
- Fix: Save and restore scrollY.
